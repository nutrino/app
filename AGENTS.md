# Project workflow

- After completing and validating requested changes, commit them and push to
  `origin` on the current branch. The user has authorized this workflow for
  future work in this project; do not ask again for routine commits and pushes.
- Review the staged diff before committing. Do not commit credentials, local
  bookmark backups, or unrelated changes unless the user has included them in
  the requested commit.
- Do not force-push or rewrite published history without explicit authorization.
